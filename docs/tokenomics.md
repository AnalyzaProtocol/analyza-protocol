# Tokenomics

_Status: no token has been announced._

Analyza has not stated a token, a contract address, a supply or a distribution. This page intentionally contains no figures, because inventing them would put unverified claims in front of readers.

## What will be published

When a token is announced, this page will list, in one place:

| Item | Detail to be stated |
| --- | --- |
| Contract | Address on Robinhood Chain (chain id 4663), mirrored in the site's top bar and the README |
| Supply | Total and circulating, with the method used to compute circulating |
| Allocation | Every allocation bucket, its size, and who controls it |
| Vesting | Any lockups or schedules, with the on-chain addresses that enforce them |
| Utility | What the token does inside Analyza, and what it does not |

## Standards the disclosure will meet

- **Verifiable on chain.** Allocation and vesting claims link to addresses a reader can inspect.
- **No hidden controls.** Mint, pause and upgrade permissions, if any, are named.
- **Same evidence bar as the product.** Analyza judges other tokens by their holder structure; its own will be presented the same way.

## Until then

Treat any token, address or presale claiming to be Analyza as unverified. The only authoritative sources are [analyza.fun](https://analyza.fun) and this repository.
