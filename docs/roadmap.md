# Roadmap

Phases are ordered by dependency, not by date. No dates are committed.

## Phase 0: Foundation _(current: in build)_

- Public site with live Robinhood Chain figures: block height, gas, TVL, active pairs
- Brand system and design tokens sampled from the logo
- Documentation set and open repository

## Phase 1: Holder reconstruction

- Transfer ingestion for a single token from chain logs
- Per-address ledger: cost, proceeds, remaining balance
- Concentration view: share of float by address band
- Visible exclusion of dust, free arrivals and contract plumbing

## Phase 2: Wallet trail

- Address linking across tokens on the chain
- Per-address history length and overlap
- Sample size shown beside every aggregate

## Phase 3: Grading

- Return bands for holders of a token
- Track-record grading from earlier positions
- Shareable read-outs for a token's crowd

## Phase 4: Open interfaces

- Documented read API
- Embeddable summaries
- Community-maintained labels for known infrastructure addresses

## How this page changes

An item moves only when it is demonstrably live. Anything not announced stays unannounced.
